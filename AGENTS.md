# Guía para de desarrollo para agentes

## Instrucciones generales

- Utiliza el lenguaje Java 25 o superior.
- Utiliza el framework Spring Boot 4 y Spring Framework 7.
- Utiliza Maven como gestor de dependencias.
- Utiliza buenas prácticas de programación.
- Utiliza patrones de diseño cuando sea apropiado.
- Escribe código limpio y mantenible.
- Idioma de los ejemplos y documentación: Español.
